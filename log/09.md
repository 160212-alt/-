오늘 결정한 것:
지역별 인구 1만 명당 의사 수와 주관적 건강수준 인지율의 관계를 분석하는 Streamlit 웹페이지를 제작하기로 했다. 질문, 데이터 분석, 기준선, 모델 평가의 4개 메뉴로 구성하고, 평균 모델과 선형회귀 모델의 성능을 비교하기로 했다.
AI에게 보낸 프롬프트(원문):
"KOSIS의 지역별 인구 1만 명당 의사 수와 주관적 건강수준 인지율을 활용하여 Streamlit 페이지를 만들어 줘. 질문, 데이터 분석, 기준선, 모델 평가 메뉴를 구성하고, 상관관계와 선형회귀 분석을 포함해 줘. R², MAE, RMSE를 활용하여 평균 모델과 선형회귀 모델의 성능을 비교해 줘. 구글 드라이브나 CSV 파일을 사용하지 않고 데이터를 코드에 직접 입력하는 방식으로 작성해 줘."
AI가 준 것 중 고치거나 버린 것과 그 이유:
처음 제공된 코드에서 실제로 사용하지 않는 CSV 업로드 및 다운로드 기능을 삭제했다. 또한 분류와 군집 분석은 현재 데이터가 3개 지역뿐이어서 신뢰성 있는 평가가 어렵다고 판단해 실제 계산 기능 대신 평가 지표와 분석 방법을 설명하는 방식으로 수정했다.
느낀 점:
AI를 활용하면 복잡한 코드를 빠르게 작성하고 다양한 분석 기능을 구현할 수 있다는 점을 알게 되었다. 하지만 AI가 제공하는 데이터가 항상 정확한 것은 아니므로 통계 자료의 출처와 신뢰성을 직접 확인하는 과정이 중요하다고 느꼈다.
AI 없이 내가 스스로 한 것:
탐구 주제를 직접 선정하고 의사 수와 주관적 건강수준 인지율의 관계라는 핵심 질문을 설정했다. 또한 분석에 필요한 데이터의 종류를 결정하고, 웹페이지에 필요한 메뉴와 전체적인 분석 방향을 구상했다.
